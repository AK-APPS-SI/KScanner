How KScanner stores a scan, how search works, and what happens if you delete the app.

Does KScanner work offline?

Yes. Scanning, reading, search, and the library run on the iPhone. A network connection is not required to open documents you have already saved. Voice search may need Apple’s speech service if the device cannot recognize speech on its own.

Do I need an account?

No. KScanner does not ask you to sign in, and there is no profile tied to your documents.

Are my scans uploaded?

No. KScanner does not operate a server that receives your pages. This version does not sync the library with iCloud. A file leaves the iPhone when you share it, or when you export a zip and save that zip somewhere else.

Does KScanner use a cloud AI service?

Text recognition and search are designed to run on the device. KScanner does not send your pages to a third-party cloud AI service. Optional voice search uses Apple’s Speech framework. When on-device recognition is available, KScanner requires it. If it is not available, Apple may process the audio to return text, under Apple’s Privacy Policy. KScanner does not keep a recording.

Can I move my library to another iPhone?

Not automatically. Export a library zip from Settings on the current iPhone, copy that file, then import it on the new one. Import can replace what is on the new iPhone, or add a duplicate and leave the existing library in place. Keep the zip until you have confirmed the import.

What happens if I delete the app?

The library stored by KScanner is deleted with the app. A zip you already exported is not deleted, because that file lives wherever you saved it. Install KScanner again and import the zip if you want those documents back.

What is in the library zip?

The export is a zip of the documents KScanner is keeping, including documents in Trash. Import asks before it replaces the library on that iPhone or adds a copy.

Which formats can I share?

PDF, Word, PowerPoint, Excel, JPEG, and text. PDF quality — High, Balanced, or Compact — is chosen in Settings → Scanning. Text is available after the page has been read.

If I password-protect a PDF, does KScanner remember the password?

No. The password is applied to the file you share. It is not saved in the app. Keep it somewhere you will remember. KScanner cannot recover it later.

Can I correct a title or a missed word?

Yes. A suggested title can be renamed, and you can change the document type. Recognition is an aid. It will not read every page perfectly, especially small print, glare, or handwriting.

Does KScanner track my location?

No. KScanner does not request location access. Folders are labels you choose, not places on a map.

Does KScanner show ads?

No. The current app does not include advertising.

Is a signature in the app a legal e-signature?

A signature you place is a mark stored with that document on the iPhone. KScanner is not a certified electronic-signature service and does not verify identity.

How do I contact support?

Email mail.ak.apps@gmail.com. Include the version from Settings → About, your iOS version, and a short description of the issue. Do not send passwords or payment details.
