01 · GETTING STARTED

Scan the first page

KScanner opens ready to scan. You do not create an account. The camera finds the page, and you can check it before it is saved.

Add a document

  1. Tap Scan. Auto is the usual starting point.
  2. Capture one page, or keep adding pages to the same document.
  3. Review the crop. Rotate a page if the orientation is wrong.
  4. Save. KScanner suggests a title from the scan and the date. Rename it whenever you like.

If you already have a photo or a file, import it. An import does not have to begin in the camera. Place the result in a folder, or leave it in the library.

Tip Even light and a page that fills the frame give the camera a cleaner edge to follow.
02 · READING

Text stays on the device

After a scan, KScanner reads the page on the iPhone. That text is what search uses, and what a text export contains. You can correct a title or the document type if the suggestion is off.

Reading follows the languages the iPhone already uses. In Settings → Reading you can narrow that to specific languages when a stack of pages is in one language, or turn Automatic back on.

If a line is missed Small type, glare, and handwriting are harder to read. Retake the page, or type the title yourself. Recognition assists entry. It does not certify the text.
03 · SEARCH

Find the page, not just the file name

Search looks through the text read from your documents. Open a result and KScanner can take you to the page that matched. Recent searches stay on the iPhone until you clear them in Settings → Library.

Voice search is optional. The first time you use it, iOS asks for speech recognition and the microphone. KScanner does not keep a recording. When the device can recognize speech on its own, that is what it uses.

04 · ORGANIZE

Folders, favorites, and trash

File a document in a folder, mark it as a favorite, or leave it in the main library. Deleting moves it to Trash. Trash keeps it until you delete it permanently. Permanent deletion removes the copy KScanner stored.

You can sign a page and mark it up. A signature is stored with that document on this iPhone. It is a mark on the page, not a certified electronic-signature service.

05 · SHARE

A file is created when you ask for one

Share can produce a PDF, a Word file, a PowerPoint file, an Excel file, JPEG pages, or plain text. Nothing is copied to another app until you pick a destination in the share sheet.

PDF quality is set in Settings → Scanning: High, Balanced, or Compact. High stays closest to the scan. Compact makes a smaller file.

You may protect a PDF with a password. Anyone who opens that PDF needs the password. KScanner does not save the password in the app. If you forget it, the protected file cannot be opened from that password later.

Text export A text file is available after the page has been read. If nothing has been read yet, KScanner will say so.
06 · BACKUP

Keep a copy you control

This version stores the library on the iPhone. It does not sync documents through iCloud. The way to move a library is a zip you export yourself.

Before you switch devices or delete the app

  • Open Settings and export the library. The zip includes documents in Trash.
  • Save that zip somewhere you control — Files, another device, or a drive you manage. Putting the zip in iCloud Drive is your choice. It is not automatic sync.
  • On the new install, import the zip. You can replace the library on that iPhone, or add the zip as a duplicate and keep what is already there.
Important Deleting KScanner deletes the library stored by the app. Import a zip you already saved if you want those documents back.
07 · LOCK

Cover the pages when you leave

Settings → Lock can require Face ID, Touch ID, or your device passcode when you return to KScanner. While that lock is on, the app switcher hides the pages. Set a passcode on the iPhone before you turn the lock on.

A lock on one document is separate. It stays on that document.
