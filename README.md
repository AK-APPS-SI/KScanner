# KScanner Support Website

Public static support site for KScanner, a private document scanner for iPhone.

## Pages

- `index.html` — Product introduction
- `support.html` — Guides for scanning, reading, search, sharing, backup, and lock
- `faq.html` — Frequently asked questions
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Use
- `styles.css` — Shared styling

The copy matches the current app: documents stay on the device, there is no account, and this version does not sync a library with iCloud. It does not describe subscriptions, because the current app does not sell them.

Support email: `mail.ak.apps@gmail.com`.

The app icon is `images/kscanner-icon.png`. Product screenshots are in `images/screenshots/`.

## GitHub Pages

1. Publish this folder as a public site.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for the site to publish.

Paths are relative, so the same files work at a repository root or in a project subpath.

## Before App Store submission

Confirm the Privacy Policy still matches the build you submit, including permissions, on-device speech, and any future iCloud or purchase behavior. Add the App Store link once KScanner has a listing. Do not point the download badge at another app.

This site contains no app source code, secrets, API keys, or credentials.
